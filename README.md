# Multi-PDF RAG Application

## Project Description

A Retrieval Augmented Generation application
that allows users to upload multiple PDF documents
and ask questions across all uploaded documents.

## Technologies

- Python
- Streamlit
- LangChain
- OpenAI Embeddings
- FAISS
- PyPDF

## Features

1. Multiple PDF uploads
2. PDF text extraction
3. Text chunking
4. Embedding generation
5. Single FAISS vector database
6. Question answering
7. Source filename and page citations
8. Conflict-aware answer generation

## Installation

pip install -r requirements.txt

## Run Application

streamlit run rag_app.py

## Environment Variable

Set OPENAI_API_KEY before running.
